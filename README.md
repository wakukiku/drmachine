# drmachine

Минималистичная браузерная драм-машина на Vue 3 и Web Audio API.

## Возможности

- 6 синтезируемых инструментов: бочка, малый, хлопок, хэт, перкуссия и бас;
- 16-шаговый секвенсор;
- 4 независимых паттерна;
- темп 60–200 уд/мин;
- свинг и мастер-громкость;
- усиление, высота, затухание и фильтр отдельно для каждого инструмента;
- предпрослушивание выбранного инструмента;
- индикатор выходного уровня;
- сохранение паттернов и параметров в LocalStorage;
- адаптивная вёрстка;
- мягкие анимации шагов, ручек и ползунков.

Звуки создаются прямо в браузере средствами Web Audio API — внешние аудиофайлы не требуются.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```
